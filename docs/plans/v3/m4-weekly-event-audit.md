## M4 新增项核对

| M4 项 | 周常压力判断 | 说明 |
|---|---|---|
| 结契 / 解除 | 非周期 | 关系建立与解除按需发生；解除有灵石费用与 7 天冷却，防频繁刷关系 |
| 双修重叠折算 | 0 分钟新增 | 只在双方闭关区间重叠时被动折算，收功路径统一展示，不要求同步在线 |
| 每日互赠 | 非周必做 | 白名单绑定小物，额度极小；错过不影响境界、道途、飞升主线 |
| 专属展示 / 合击播报 | 0 分钟新增 | 面板与 Boss 文案展示，无数值收益 |
| 同步共修仪式 | 可选限周 | 每人每周 1 次，错过不补；给愿意相约的道友一点仪式感，不作为必修课 |
| 周活动双人任务 | 可选限周 | 复用周活动完成记录，异步达成；道行进入既有活动周上限 |

## 结论

M4 不新增“必须每周上线完成”的事务。新增的同步共修仪式与周活动双人任务均明确标记为**可错过无惩罚**：共修是每周一次的主动协作小玩法，交互 <2 分钟且错过不补；双人任务不要求实时组队，若双方本来完成周活动则 0 新增操作，奖励也吃既有 `WEEKLY_DAOHANG_CAP=300`。

因此，活跃玩家的周必做总耗时不随 M4 增长。若玩家自愿参与全部 M4 新增协作项，额外手动交互仍受控在约 2 分钟 / 周，且 30 分钟共修为活动窗口等待，不构成新的高压周常。
