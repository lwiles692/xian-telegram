# V3-M3 周事件总量审计

审计日期：2026-07-09

审计范围：V3-M3「师徒 + 新角色引导」已落地的拜师、传承、活跃天数、出师、桃李称号与师父周活跃回报；核对是否新增必须每周定时完成的玩家事务，避免社交系统把留存奖励变成额外周常负担。

| 事项 | 周期 / 频率 | 是否 M3 新增周必做 | 玩家动作 | 预估交互耗时 | 处理结论 |
|---|---:|---:|---|---:|---|
| 拜师 / 解除 | 按需 | 否 | 双方确认或单方解除 | 单次 <1 分钟 | 属于关系建立流程，无周期奖励压力；解除后 7 天冷却防频繁重拜 |
| 徒弟 +5% 闭关效率 | 被动常驻 | 否 | 无需额外操作 | 0 | 只在 active 师徒且出师前生效，并入 SECLUSION clamp，不新增日常动作 |
| 每日传功 | 每对师徒每日一次 | 否 | 师父按需发起，且徒弟当日已有前台行为 | 单次 <1 分钟 | 可错过无惩罚；徒弟活跃门槛防纯签到领取 |
| 活跃天数记录 | 每日首个前台行为 | 否 | 沿用闭关收功 / 历练 / 秘境 / 悬赏领取 | 0 | 复用既有前台结算点，记录随行为发生，不要求新增指令 |
| 突破里程碑奖励 | 徒弟破金丹 / 元婴时一次性 | 否 | 无额外动作 | 0 | 绑定在突破结算内，每师徒每里程碑终身一次 |
| 出师 | 达元婴初期且累计活跃达标后按需 | 否 | 任一方触发出师 | 单次 <1 分钟 | 一次性收束 active 关系，后续传承和周回报停止 |
| 师父周活跃回报 | 周日 23:40 被动结算 | 否 | 无需在线、无需领取 | 0 | APScheduler 被动发放；按周键幂等，计入道行周上限，不新增资源入口 |

结论：M3 当前新增的是师徒关系承接与被动传承收益，不新增必须定时上线完成的周任务。师父周活跃回报虽然按周结算，但玩家无需领取或排队参与，且收益来源于徒弟本周既有前台行为；3 名满勤 active 徒弟合计 90 道行 / 周，低于 `OVERFLOW_DAOHANG_WEEKLY_CAP=600`，并受同一周上限约束。后续 T3.7 七日引导任务链上线前，应继续复核是否把新手引导设计成可自然完成，而非额外周常。
