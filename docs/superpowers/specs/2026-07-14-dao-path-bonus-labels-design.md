# 道途加成中文描述设计

## 目标

道途页面展示加成时，不再暴露 `seclusion_pct`、`spd_pct` 等内部参数名，改用与法宝页面一致的中文属性描述。

示例：

```text
符阵·大成·淬炼2（当前）：闭关加成+11%、速度加成+6%
```

## 根因

法宝页面通过 `config.items.format_bonus()` 格式化属性；道途页面则在 `handlers.dao_path._bonus_text()` 内直接拼接字典键名。两套展示逻辑分叉，导致道途泄露内部参数名。

## 方案

让道途页面复用 `config.items.format_bonus()`，并在其中文标签映射中补齐道途涉及的属性：法力加成、暴击加成、速度加成、丹术加成、炼器加成、闭关加成。

保留现有数值规则：`_pct` 属性继续按百分比显示，空属性继续由道途页面显示为“无”。不修改道途数值、数据库或业务服务。

## 测试

先新增处理器级回归测试，构造包含闭关与速度百分比的道途加成，断言输出为中文描述且不包含内部参数名。确认测试在修改前失败后，再实现最小修复，最后运行完整 `python -m pytest`。
