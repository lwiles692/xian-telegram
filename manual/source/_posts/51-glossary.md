本卷收录手册与游戏内常见的名词术语，按主题分组，每组一表，便于检索。

> 词条释义只述规则与用途，不涉内部数值；具体数字以游戏内实际显示为准。拿不准某个说法时，先查此处，再按词条中的链接去读对应章节。

## 基础概念

| 术语 | 释义 |
| --- | --- |
| 修为 | 经验值，闭关与历练的主要产出。积攒至当前阶段上限，即可尝试突破。 |
| 境界 | 修士的等级体系：炼气、筑基、金丹、元婴、化神、炼虚六大境界，炼虚圆满为当前顶点。详见[境界体系总览](/manual/11-realms/)。 |
| 小阶 | 大境界之内的细分阶段，如「炼气一层」。小阶修满行小突破，跨大境界行大突破。 |
| 灵根 | 创建角色时「测灵根」所得的资质品类，如金灵根、五行杂灵根。 |
| 根骨 | 养成元属性，影响闭关收益与突破成功率；可用洗髓丹、天材地宝提升。 |
| 道号 | 玩家的名号。群内切磋可以 `/pvp @道号` 点名对手，排行与播报中也以道号示人。 |

## 资源货币

| 术语 | 释义 |
| --- | --- |
| 灵石 | 主货币。购物、炼制、强化、加速、购买精力、创建宗门等处处使用；签到、历练、悬赏、宗门任务与玩家交易是常见来源。 |
| 精力 | 主动行为资源，历练、秘境、周活动、世界 Boss 与宗门战都要消耗。随时间自然恢复，空槽回满约需 6 至 10 小时（随境界递增）；超出上限的精力不会被截断。详见[核心资源总览](/manual/02-resources/)。 |
| 气血 | 战斗生命。跨活动保留，不会每场自动回满；战败保底不低于上限两成。 |
| 法力 | 施放战技的资源，同样跨活动保留；法力不足时，战斗中会多次转为普通攻击。 |
| 道行 | 长期资源，用于道途升阶与飞升试炼。常见来源有周活动副本、高境界圆满后的溢出修为转换、PvP 月赛季与宗门战赛季奖励。 |
| 飞升点 | 飞升体系的账号级资源，用于升级飞升被动与叩问天门。详见[飞升](/manual/40-ascension/)。 |
| 宗门贡献 | 宗门内的个人功绩，由宗门任务与捐输获得，可在宗门商店兑换残页、丹方、图纸等物品。 |
| 声望 | 切磋体系的荣誉。天梯积分即时变动，灵石奖励按周声望排名结算奖池；同一对手每日只计一次有效声望。 |

## 修炼突破

| 术语 | 释义 |
| --- | --- |
| 闭关 | 积攒修为的主要方式。发送 `/cultivate` 开始，真实时间流逝即涨修为，离线期间也在积累。详见[闭关与突破](/manual/10-cultivation/)。 |
| 出关 | 再次发送 `/cultivate` 或点击闭关按钮收功，结算本次闭关所得修为。 |
| 离线结算上限 | 单次闭关收益有时间上限，超出部分不再累积；出关后再次闭关，即可分多次持续推进。 |
| 活动窗口 | 历练、秘境、周活动等前台行为留下的记录。闭关是后台被动轨，前台行为会折算闭关收益，避免两轨同时满额。 |
| 突破 | 修为达到当前阶段要求后尝试晋升，在 `/me` 面板中点击「尝试突破」操作。 |
| 小突破 | 小阶段突破，修为足够即可尝试。 |
| 大突破 | 大境界突破，需要对应突破丹，并可能触发劫数。 |
| 突破丹 | 大突破必备丹药：筑基丹、金丹、元婴丹、化神丹、炼虚丹。高阶突破丹不在 NPC 商店出售，需从困难地图、秘境、残方炼制链路与签到保底中求得。 |
| 天劫 | 金丹、元婴大突破触发的多段互动劫数，可选护体法宝、护盾战技、服用大还丹或硬抗。 |
| 神魂劫 | 元婴圆满入化神的大突破劫数。 |
| 虚空劫 | 化神圆满入炼虚的大突破劫数。 |
| 直面心魔 | 高境界劫数中可能出现的抉择选项，利弊由道友自行权衡。 |
| 道基不稳 | 突破失败留下的临时状态，战斗表现随之下降；可静待自然恢复，也可用疗伤丹清除。突破失败不跌境，但可能损失一部分当前修为。 |
| 圆满 | 大境界最后一个小阶修满的状态。版本顶点境界圆满后，继续修炼所得即为溢出修为。 |
| 溢出修为 | 境界圆满后继续获得的修为，不会白费，按规则转为道行与飞升点。 |
| 溢出凝点 | 溢出修为每累计满 100000 凝成 1 点飞升点；溢出来源每周最多凝成 14 点，不占用试炼、世界 Boss 与活动兑换的飞升点份额。 |
| 道痕 | 不足十万的溢出修为零头，跨周保留，攒满十万即凝为飞升点。 |

## 战斗属性

| 术语 | 释义 |
| --- | --- |
| 法身六维 | 角色面板上的战斗属性（攻击、防御、身法、暴击等），随境界、法宝、功法与各类加成成长，在 `/me` 中查看。 |
| 出发快照 | 历练、秘境等出发时记录当前气血与法力，整场战斗按出发状态结算；晚领取或中途服丹都不会改变该场结果。 |
| 重伤而归 | 战败结算的保底：气血不会低于上限两成，修为与装备不受损失。 |

## 物品装备

| 术语 | 释义 |
| --- | --- |
| 法宝 | 装备总称，分主器、护体、饰品三类槽位，影响战斗表现。详见[法宝·功法·本命法宝](/manual/33-skills/)。 |
| 品阶 | 法宝的品质等阶，自低而高为凡、灵、宝、玄四阶。 |
| 词条 | 法宝实例上的随机附加属性；重铸可消耗灵石与器魂重掷词条。 |
| 主器 | 攻伐向法宝槽位，仅 1 个。 |
| 护体 | 防护向法宝槽位，仅 1 个。 |
| 饰品 | 辅助向法宝槽位，共 2 个。 |
| 本命法宝 | 元婴期起为宝阶或玄阶法宝举行认主仪式后所得的身份：等级自 Lv1 起，最高 Lv10，认主后立即绑定。 |
| 认主 | 将宝阶或玄阶法宝立为本命的仪式，需消耗灵石与材料；认主前请想清楚，本命与绑定法宝不可上拍、不可分解。 |
| 喂养 | 本命法宝的长线养成，消耗灵石、器魂与高阶材料提升本命等级；不按每日或每周重置，错过不罚、不补课。 |
| 斩缚 | 解除当前本命指向的操作：清空原本命等级；该法宝仍保持绑定，不可再次认主，也不能重新流入交易或分解套现。 |
| 器魂 | 分解未装备、未绑定且非本命的法宝所得，用于法宝强化与重铸。 |
| 功法 | 心法与战技的合称。 |
| 心法 | 被动功法，同时只能装备 1 个；初始心法为吐纳诀。 |
| 战技 | 战斗中施放的主动功法，最多装备 3 个，消耗法力；初始战技为快剑斩。 |
| 残页 | 功法残卷，集齐后可在 `/skills` 中学习对应功法。 |
| 丹方 | 炼丹配方书，研读后解锁对应丹药的炼制。 |
| 图纸 | 炼器配方书，研读后解锁对应法宝的炼制。 |
| 炼丹 | 以材料炼制丹药，筑基后开放；开炉后需等待出炉，可用灵石加速。详见[炼丹与炼器](/manual/32-craft/)。 |
| 炼器 | 以材料与图纸炼制法宝，成品可能附带随机词条。 |
| 储物袋 | `/bag` 背包，分可使用、丹药、材料、残页、法宝五页。 |
| 绑定物 | 与角色绑定的物品，不能在坊市上架、不能上拍；活动奖励、签到保底丹、七日引导奖励等多为绑定。 |

## 社交组织

| 术语 | 释义 |
| --- | --- |
| 宗门 | 玩家组织。筑基后可创建或加入，有宗门任务、商店、捐输与等级福利（精力上限、闭关效率、掉落加成、离线上限等）。详见[宗门](/manual/36-sect/)。 |
| 捐输 | 向宗门捐献灵石换取个人贡献的方式，每日有上限；宗门贡献池另用于宗门升级。 |
| 师徒 | 新角色承接与高境界传承的关系：师父需元婴期及以上，徒弟需筑基圆满及以下；以 `/master` 拜师或收徒，另一方确认后生效。详见[师徒与道侣](/manual/38-bonds/)。 |
| 传功 | 师父每日可向当日活跃的徒弟传功一次；徒弟出师前享有闭关传承加成。 |
| 出师 | 徒弟达元婴初期且累计活跃天数达标后，可在 `/master` 中出师；解除师徒后双方进入 7 天冷却。 |
| 道侣 | 双向同修关系，双方需金丹期及以上；提供仪式协作与少量同修收益，不提供战斗数值加成。 |
| 结契 | 结成道侣的仪式：`/partner 结契` 发起，另一方确认后生效，确认时消耗 1 枚绑定同心结。 |
| 同心结 | 结契所需信物，可经炼器制得，也可在周活动商店兑换。 |
| 共修 | 师徒与道侣跨关系共享的仪式协作，每人每周 1 次：一方邀请、另一方 10 分钟内确认，30 分钟后收束领奖；错过无惩罚。 |
| 同参 | 道侣双方闭关区间重叠时，收功显示的同修时长；重叠部分折算为少量额外修为。 |

## 玩法活动

| 术语 | 释义 |
| --- | --- |
| 历练 | `/explore` 消耗精力刷图，获取灵石、材料、丹药与突破资源；每个大境界有易、中、难三张地图。详见[历练与奇遇](/manual/30-explore/)。 |
| 低阶历练 | `/explore` 中展开的低境界地图，用于刷低阶材料或补突破资源。 |
| 扫荡 | 本境界地图连续胜利 3 次后解锁的速通方式：立即结算，仍消耗精力，仍复用战斗与掉落规则。 |
| 奇遇 | 历练中偶发的低频事件（如坠崖洞府），可在冒险探入、稳妥绕行、救人之间抉择。 |
| 秘境 | `/dungeon` 多层 PvE 副本，固定约 30 分钟完成，逐层结算；有独立每日次数，部分秘境另收入场费。详见[秘境副本](/manual/31-dungeon/)。 |
| 妖王 | 地图精英与副本首领，难图遭遇率更高，收益也更丰厚。 |
| 世界 Boss | 群内定时合击的强敌，每日 20:00（上海时间）在已记录的群中刷新；血量按群内已知修仙者人数缩放，击败或到期后按参与情况发奖。详见[切磋·天梯·世界Boss](/manual/43-pvp/)。 |
| 宗门战 | 每周六 20:00-21:00（上海时间）开放的据点争夺，`/sectwar` 进入；挑战据点守卫，为宗门累计积分。详见[宗门战据点](/manual/37-sectwar/)。 |
| 据点 | 宗门战的争夺对象：洞府（闭关效率）、矿脉（掉落加成）、祭坛（法身属性）；加成为轻量加成，进入全局合算上限。 |
| 赛季 | 周期性结算：宗门战按月末赛季向夺魁宗门成员发道行；天梯另有周榜奖池与月赛季奖励。 |
| 悬赏 | `/quest` 中的目标清单，含七日引导、日常、周常与成就四类。详见[签到与悬赏任务](/manual/35-quest/)。 |
| 七日引导 | 新角色注册起 7 天内逐日开启的教学任务，物品奖励均为绑定；已有师父者完成时师徒双方另有联动奖励。 |
| 签到 | `/daily` 每日一次，得灵石与 10 点精力；元婴圆满缺化神丹、化神圆满缺炼虚丹时，签到另有绑定丹保底。 |
| 连签 | 连续签到的天数记录。 |
| 周活动 | `/weekly` 每周一个主题副本（如天魔潮、丹霞会、万剑冢），产出道行与本周主题绑定材料。详见[周活动副本](/manual/41-weekly/)。 |
| 活动材料 | 周活动产出的主题材料（天魔令、丹霞玉、剑冢铁），在活动商店使用。 |
| 活动商店 | 以活动材料兑换绑定保命符、转修令、道途材料或飞升点的商店。 |
| 切磋 | 群内 1v1，`/pvp` 发起；不掉资源，只影响天梯积分与声望。 |
| 天梯 | 切磋的排行体系，积分即时变动，灵石奖励按周声望排名结算奖池。 |
| 段位 | 天梯积分对应的段位，连同胜负记录在 `/rank` 中展示。 |

## 经济交易

| 术语 | 释义 |
| --- | --- |
| 坊市 | `/market` 玩家一口价交易，私聊使用；当前主要交易非绑定的堆叠物品（材料、丹药等），不交易法宝实例。详见[坊市与拍卖行](/manual/42-market-auction/)。 |
| 拍卖行 | `/auction` 竞价交易，承接带词条的法宝实例与白名单高阶材料；英式拍卖，拍期 24 小时，每人同时至多挂拍 3 件。 |
| 系统底价 | 拍卖起拍价的下限，按法宝品阶而定；起拍价由卖家自定，但不得低于此价。 |
| 白名单 | 拍卖行允许上拍的高阶材料名单，目前有星陨砂、幽都魂晶、天外残玉、雾泽虚砂、裂海空髓、混沌残核等；名单外的普通材料与丹药请走坊市。 |
| 一口价 | 拍卖中可选的买断价，须不低于起拍价的 1.2 倍；出价满一口价即立即成交，不进入延时。 |
| 挂拍费 | 挂拍时收取起拍价的 1%（至少 1 灵石），流拍、撤拍均不退还。 |
| 成交税 | 成交后从卖家货款中扣除的税；拍卖行为成交价的一成，坊市挂单同样在成交时扣税。 |
| 延时 | 防狙击机制：结拍前 5 分钟内有人出价，结拍时间顺延 5 分钟，至多顺延 6 次。 |
| 托管 | 法宝实例上拍后进入拍卖托管状态，期间不可装备、强化、重铸、分解或再次上拍，成交过户或流拍退回后解除。 |
| 流拍 | 拍期结束仍无人出价，物品退回卖家，挂拍费不退。 |
| 撤拍 | 无人出价时卖家可撤回挂拍，物品返还，挂拍费不退。 |
