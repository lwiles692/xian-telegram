宗门是修仙者聚集的组织，提供任务、商店与多项福利，是中后期修仙的重要支撑。加入宗门后，道友可享受精力上限、闭关效率、掉落加成等增益，并参与宗门战争夺据点。

## 宗门概览

宗门定位为玩家组织玩法，通过成员共同参与任务、捐输与升级，提升宗门等级并解锁更强福利。

宗门等级带来的福利包括：

- 精力上限增加
- 闭关效率提升
- 掉落加成提高
- 离线上限延长

这些福利直接助力修仙者的日常修炼与资源获取，是宗门成员的核心收益来源。

## 创建与加入宗门

### 创建宗门

筑基期及以上的修仙者可创建宗门。创建需消耗灵石，并拟定宗门名称。

创建指令：

```text
/sect create 宗门名
```

创建者自动成为宗主，拥有升级宗门等管理权限。

### 加入宗门

任何境界的修仙者均可加入已有宗门。

加入指令：

```text
/sect join 宗门名
```

加入宗门后即可开始享受宗门福利、完成任务与在商店兑换物品。

## 宗门指令

宗门相关的主要指令如下：

| 指令 | 用途 |
| --- | --- |
| `/sect` | 查看宗门信息 |
| `/sect create 宗门名` | 创建宗门 |
| `/sect join 宗门名` | 加入宗门 |
| `/sect task` | 领取宗门任务 |
| `/sect donate 数量` | 捐输灵石换取贡献 |
| `/sect leave` | 离开当前宗门 |
| `/sect upgrade` | 宗主升级宗门 |
| `/sect buy 物品名` | 在宗门商店兑换物品 |

## 宗门任务

宗门任务是每日必做内容，完成后可获得个人贡献、灵石与精力。

宗门任务奖励：

- 个人贡献 10 点
- 灵石 30
- 精力 20 点

任务每日刷新，建议上线后优先完成，既贡献宗门又补充个人资源。

## 捐输系统

捐输是获取宗门贡献的重要途径，可用于在宗门商店兑换物品。

### 捐输规则

- 以灵石换取个人贡献
- 每日捐输有上限，超过上限后当日无法继续捐输

捐输指令：

```text
/sect donate 数量
```

捐输既可提升个人贡献，也为宗门贡献池提供资源，供宗主升级宗门使用。

## 宗门商店

宗门商店提供多种珍稀物品，需消耗个人贡献兑换。

当前可兑换物品：

| 物品 | 贡献消耗 | 说明 |
| --- | ---: | --- |
| 归元心法残页 | 20 | 心法残页，集齐后可学习归元心法 |
| 烈火诀残页 | 20 | 心法残页，集齐后可学习烈火诀 |
| 回春术残页 | 20 | 心法残页，集齐后可学习回春术 |
| 玄铁剑图纸 | 35 | 炼器图纸，解锁玄铁剑配方 |
| 洗髓丹丹方 | 45 | 炼丹丹方，解锁洗髓丹配方 |
| 聚灵佩图纸 | 45 | 炼器图纸，解锁聚灵佩配方 |

宗门商店兑换指令：

```text
/sect buy 物品名
```

建议优先兑换功法残页与配方，提升战力与炼制能力。

## 宗门等级与升级

### 宗门等级福利

宗门等级越高，提供的福利越强。具体福利提升包括：

- 精力上限：每级提升 5 点
- 闭关效率：每级提升 5%
- 掉落加成：每级提升 3%
- 离线上限：每级延长 1 小时
- 法身属性：每级提升 2%

这些福利有上限，达到上限后继续升级不再提升对应项。

### 宗门升级

宗主可消耗宗门贡献池与灵石升级宗门。

升级指令：

```text
/sect upgrade
```

升级消耗：

- 宗门贡献池（成员捐输累积）
- 宗主个人灵石

升级后全体成员立即享受更高的宗门福利，因此鼓励成员积极参与任务与捐输。

## 离开宗门

修仙者可随时离开当前宗门。

离开指令：

```text
/sect leave
```

离开后，个人贡献记录会随成员身份一同清除，宗门福利亦随之失去。若日后加入新宗门，个人贡献需从头积累。

## 宗门管理

宗主除升级宗门外，还肩负管理职责：

- 带领成员完成宗门任务
- 鼓励成员捐输贡献池
- 合理规划升级时机
- 组织成员参与宗门战

一个活跃的宗门能更快提升等级，为全体成员提供更强福利。
