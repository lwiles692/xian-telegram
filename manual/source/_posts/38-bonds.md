仙途漫漫，独修易倦。《问道》设有师徒与道侣两种长期关系：前者用于新角色承接与高境界传承，后者用于道友之间的长期同修与少量仪式协作。两者都以私聊指令 `/master`、`/partner` 管理，均**不提供任何战斗数值加成**，错过亦无惩罚，属于锦上添花的社交长线。

## 师徒 `/master`

### 名分门槛

- 师父需**元婴期及以上**，方可开坛授业。
- 徒弟需**筑基圆满及以下**，方可入门承教。
- 一位师父门下同时最多三名在册徒弟；一名徒弟同一时刻只有一位师父。

境界差是硬门槛，已有一定修为的角色无法互拜刷奖。

### 拜师与收徒

任一方都可发起，双向确认后名分方立：

```text
/master 拜师 对方ID
/master 收徒 对方ID
```

- 拜师与收徒是同一桩缘法的两个方向：想认人为师用「拜师」，想纳人入门用「收徒」，另一方确认后效果相同。
- 在群聊中**回复对方的消息**再发送 `/master 拜师` 或 `/master 收徒`，可省略对方 ID。
- 在群聊发起时，确认页会发到**发起人的私聊**；若尚未与机器人私聊过，请先在私聊发送 `/start`，再重新回复对方发送指令。
- 递帖后对方会在 `/master` 面板看到「待你确认」的拜师帖，需由另一方亲自确认，不可自证。

完整流程如下：

1. 任一方按上述方式递出拜师帖。
2. 另一方打开 `/master`，在「待你确认」中同意或婉拒。
3. 确认即写入名分，师徒关系当下生效；师父面板「门下弟子」与徒弟面板「师父」一栏随之更新。

拜师帖的几种结局：

| 结局 | 后果 |
| --- | --- |
| 对方确认 | 名分成立，传承即刻开始 |
| 对方婉拒 | 帖子作废，双方不产生冷却，可另行递帖 |
| 约两日未应 | 帖子过期作废，同样不产生冷却 |

> 拜师帖确认页会明示：「解除后重拜，出师累计活跃天数从 0 重计。」递帖之前，请师徒双方都已知晓此规。

### 传承收益

| 收益 | 对象 | 说明 |
| --- | --- | --- |
| 闭关传承加成 | 徒弟 | 出师前闭关有一份小额传承加成，并入闭关增益总上限；若加成被上限截断，收功时会提示已达闭关增益上限 |
| 每日传功 | 徒弟 | 师父每日可向每名**当日已有前台修行**的徒弟传功一次，徒弟得小额修为，师父无消耗 |
| 突破里程碑 | 师父 | 徒弟突破金丹、元婴大境界时，师父获得道行与群内播报；每名徒弟每档只发一次 |
| 周活跃回报 | 师父 | 每周按徒弟的活跃天数结算小额道行，计入道行周上限；徒弟出师后停发 |
| 出师传承礼 | 双方 | 出师时双方各得道行与绑定材料（天材地宝、妖丹），师父另积桃李称号进度 |

所谓「当日已有前台修行」，指徒弟当日有过闭关、历练、秘境、悬赏等任一前台行为；仅签到站桩的徒弟当日不可受功。传功只是提携后进的一点助力，额度远低于徒弟自己闭关的所得，是「加速」而非「代练」。

此外，若徒弟是新注册角色，完成七日引导任务时师徒双方还会各得一份小额联动奖励。

### 出师

徒弟达成以下条件后，可在 `/master` 中出师（师父也可代为点出师）：

- 境界达到**元婴初期**；
- 拜师后**累计活跃满 8 日**——有任一前台修行行为即记 1 活跃天，面板会显示「活跃 X/8 日」。

出师后这段师徒缘记为「功成出师」：传承加成与传功随之结束，已发放的奖励不回收。

师父另有桃李长线：累计出师 1、3、5 名徒弟，依次解锁「授业真人」「桃李盈门」「一代宗师」称号，并在群内播报。

### 解除与重拜

- 任一方可单方解除师徒关系。
- 解除后双方进入 **7 天冷却**，冷却期内不能再结新师徒。
- 解除后重拜新师父，出师所需的累计活跃天数**从 0 重计**；已发放的里程碑奖励不回收，但同一对师徒的每个里程碑终身只发一次。

## 道侣 `/partner`

### 结契

- 双方均需**金丹期及以上**；一人同一时刻只有一位道侣。
- 任一方发送 `/partner 结契 对方ID` 发起；在群聊中回复对方消息发送 `/partner 结契` 可省略 ID，确认页同样发到发起人的私聊。
- 对方确认结契时，消耗 **1 枚绑定同心结**，道侣名分自此立下。
- 同心结可在 `/craft` 炼器制得，也可在周活动商店兑换；它属于绑定物，不可上架交易。

结契后双方获得道侣称号「比翼同修」，展示在 `/partner` 面板；合击世界 Boss 时还有专属播报文案。结契与解除都会有群内播报。

### 同参双修

双方闭关时段相叠时，收功会把**重叠部分**折算为少量额外修为，并显示同参时长，例如：

```text
与道侣同参 137 分钟，双修额外修为 +xxx
```

- 重叠只看闭关区间，不看是否同时在线；离线自动闭关的时段同样计入。
- 双方各自独立结算，一方的收功不会打断另一方的闭关。
- 双修加成并入闭关增益总上限，与宗门、道途、飞升被动等共用同一上限；被截断时收功会提示已达闭关增益上限。
- 无重叠时段则不显示该行。

### 每日互赠

道侣每日可互赠 **1 件**绑定白名单物品，面板会列出「今日可赠」。白名单只含常用丹药与基础材料：

| 类别 | 物品 |
| --- | --- |
| 丹药 | 疗伤丹、补灵丹、大还丹、虎力丹、凝神丹 |
| 材料 | 灵草、玄铁矿、妖兽皮、妖丹、天材地宝 |

赠出的物品**仍为绑定**，不可借此套现或搬运资源；不在白名单内的物品无法赠送。

### 周活动双人任务

同一周内，双方**各自**完成周活动副本，即异步达成双人任务，奖励少量道行。不要求同时在线或组队，各打各的即可；道行计入周活动的道行周上限，不新增额度。

### 共修

共修是限周的同步仪式，师徒与道侣都可发起：

1. 一方在 `/partner` 或师徒面板中「发起共修」，递出共修帖。
2. 另一方需在 **10 分钟内**确认，逾期帖子作废。
3. 确认后共修开始，**30 分钟后**可回到面板「收束共修」，双方各领一份修为礼；师徒同参时徒弟得修为、师父得少量道行。

规则要点：

- 每人**每周 1 次**，师徒与道侣跨关系共用次数——本周与道侣共修过，就不能再与徒弟共修。
- 双方均不在重伤或其他前台活动中方可开启；共修期间若被其他前台行动打断，本周次数视为已用且不发奖励。
- 共修奖励独立限周，不占闭关增益上限。
- 共修与双人任务**均可错过，无惩罚、不补课**，也不影响飞升、道途或主线养成。

### 解除

- 任一方可单方解除道侣。
- 解除需消耗一笔灵石，并使双方进入 **7 天冷却**，冷却期内不能再结契。
- 结契帖与拜师帖同理：被婉拒或约两日未应而过期，都不产生冷却。

## 两种关系速查

| 项目 | 师徒 `/master` | 道侣 `/partner` |
| --- | --- | --- |
| 门槛 | 师父元婴期以上，徒弟筑基圆满及以下 | 双方金丹期以上 |
| 发起 | `/master 拜师|收徒 对方ID`，群聊回复可省略 ID | `/partner 结契 对方ID`，群聊回复可省略 ID |
| 结成消耗 | 无 | 1 枚绑定同心结 |
| 日常收益 | 传功、传承加成、里程碑与周活跃道行 | 双修重叠折算、每日互赠、双人任务 |
| 限周协作 | 共修（与道侣共用每周 1 次） | 共修（与师徒共用每周 1 次） |
| 终局 | 徒弟元婴初期且活跃满 8 日可出师 | 长久同修，无出师一说 |
| 解除 | 任一方可解，双方 7 天冷却；重拜累计天数清零 | 任一方可解，需灵石，双方 7 天冷却 |
| 战斗加成 | 无 | 无 |

## 小结

- 师徒重「传承」：高境界道友提携新人，得桃李称号与周期性道行；新人得传承加成与传功，平稳过渡到元婴出师。
- 道侣重「同修」：同参双修、每日互赠、双人任务与每周共修，皆是轻量而长久的陪伴。
- 两者都不涉战斗数值，结与不结、修与不修，悉听道友尊便。
