本章带你在十分钟内完成从注册到第一次突破的全过程。

## 第一步：踏入仙途

在机器人**私聊**中发送：

```
/start
```

系统会为你创建角色并完成「测灵根」：

- 随机生成**根骨**（养成资质，影响闭关收益与突破成功率，可用洗髓丹、天材地宝提升）；
- 赋予灵根品类（如「金灵根」「五行杂灵根」）；
- 发放初始资源：炼气一层、灵石 100、精力满槽、新手木剑（凡阶主器）与基础战技「快剑斩」。

> 一个 Telegram 账号对应一个全局角色，私聊与任何群聊共用同一存档。

## 第二步：熟悉面板

发送 `/me` 查看角色面板：灵根根骨、境界、修为进度、灵石、精力、气血/法力、法身六维、当前法宝/心法/战技、是否在闭关、是否可突破，一目了然。

发送 `/help` 可随时查看简要指南。

## 第三步：每日签到

发送 `/daily`，领取灵石与 10 点精力。连续签到记录连签天数。

## 第四步：开始闭关

发送 `/cultivate` 进入闭关，修为随真实时间增长；再次发送 `/cultivate` 即可出关收功。闭关是修为的主要来源，离线期间也在积累（有单次离线结算上限）。

修为达到当前小阶上限后，`/me` 面板会出现「尝试突破」按钮——小阶段突破修为足够即可成功。

## 第五步：出门历练

发送 `/explore`，在青牛后山、碧萝竹海、阴风古洞三张炼气地图中选择一张，消耗精力出发。历练结束后回到 `/explore` 领取灵石、材料与掉落。

## 第六步：备丹突破

筑基大突破需要**筑基丹**：可在 `/shop` 购买，或筑基后用 `/craft` 自炼。备齐丹药、修满修为，即可在面板中尝试大境界突破。

## 推荐上手顺序

```
/start → /daily → /me → /cultivate → /explore → /bag → /craft → /skills → /sect
```

到元婴后打开 `/path` 选择道途；化神圆满后打开 `/ascension` 规划飞升。后续章节会逐一详解。
