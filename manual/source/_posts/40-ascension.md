化神圆满之后，修为并未走到尽头。飞升是自化神圆满起开放的长期成长体系：溢出修为有所归，道行有所用，飞升点有所积——即便日后突破炼虚，此路依然延续，直至炼虚圆满后的顶点溢出。本章说明飞升面板、飞升点的来路与去处，以及叩问天门的规矩。

## 开放条件

- 达到**化神圆满**即开放 `/ascension`。
- **突破炼虚后仍可继续推进**：飞升试炼、被动、溢出凝点一切照旧。
- 炼虚圆满是当前版本的修为顶点，此后继续闭关的溢出修为同样凝为飞升点。

## `/ascension` 面板

在机器人私聊发送 `/ascension`，可以看到：

- 当前**飞升点**；
- 飞升**总阶**（随被动升级累积提升）；
- 已解锁的**尊号**；
- 当前**道行**；
- 可挑战的**飞升试炼**；
- 可升级的**飞升被动**（气血 / 攻伐 / 护体 / 闭关）；
- 本周**溢出凝点**额度与**道痕**进度；
- 四项被动圆满后开放的**叩问天门**。

## 飞升点的来路

飞升点不可交易，来源共四处：

| 来源 | 规则 | 是否占溢出周上限 |
| --- | --- | --- |
| 溢出凝点 | 高境界圆满后继续闭关，溢出修为每累计 **100000** 凝成 1 点 | 占，每周最多凝成 **14** 点 |
| 飞升试炼 | 每周一次，消耗道行获得飞升点 | 不占 |
| 世界 Boss 前列 | 化神 / 炼虚档世界 Boss 伤害榜前列奖励 | 不占 |
| 周活动商店 | 以活动材料兑换飞升点 | 不占 |

### 溢出凝点的细则

- 「高境界圆满」包括：化神圆满未破炼虚、以及炼虚圆满之后。此间继续闭关，修为不再推进境界，转而凝点。
- 每满 100000 溢出修为凝成 1 点；**不足十万的零头记为「道痕」，跨周保留**，攒满十万即凝。
- 溢出来源每周最多凝成 14 点；此上限**只约束溢出这一路**，不占试炼、Boss 与活动兑换的所得。
- 达到周上限后，本周新产生的完整十万修为**不会结转**到下周；但此前留存的道痕仍在。故达限之后，不妨把精力投向试炼、Boss 与周活动。

举例来说：本周你靠溢出修为已凝成 14 点，面板的本周额度见底，此后再攒出的整十万修为便留不住；但若账上还有 60000 道痕，它会原样留到下周，与下周新溢出的修为合并，凑满十万再凝 1 点。

### 飞升点账目

面板上的飞升点是当前余额：试炼、Boss、兑换所得即时入账，升级被动与叩问天门则即时扣减。余额不足时，升级与投入都不会生效，先去来路补足。

## 飞升试炼

- 需**化神圆满**方可挑战（炼虚期自然延续资格）。
- **每周只能完成一次**，下周一过再试。
- 挑战消耗**道行**，功成获得飞升点；所需道行数目以面板显示为准。

道行来路见[道途与转修](/manual/39-dao-path/)一章：周活动、圆满溢出转换、PvP 月赛季与宗门战赛季皆有产出。

## 飞升被动

飞升点的主要去处是点亮四项账号级被动：

| 被动 | 方向 |
| --- | --- |
| 气血 | 气血上限 |
| 攻伐 | 攻击 |
| 护体 | 防御 |
| 闭关 | 闭关效率 |

- 每项被动都有等级上限（**5 级为满**），每升一级消耗飞升点，提供小幅加成。
- 各项加成均并入全局属性合算上限，不会让旧内容被彻底压扁。
- 每升一级，飞升总阶随之进一。

## 尊号

飞升总阶渐升，依次解锁尊号，展示在 `/ascension` 面板：

| 总阶 | 尊号 |
| ---: | --- |
| 1 | 飞升新秀 |
| 3 | 飞升真君 |
| 5 | 渡劫仙尊 |

尊号只是资历之证，不附带数值。

## 叩问天门

四项飞升被动**均达 5 级**后，面板开放「叩问天门」——这是飞升点更长远的去处。

### 投入规矩

- 每次可投入 **100、1000、10000 点**，或将当前飞升点**全部投入**。
- 叩开下一重所需为 `100 × 2^当前重数`，依此倍增。
- 一次投入不足一重也无妨，**进度永久保留**，日后续投直至叩开。
- 投入**不可撤回**，且天门不提供无限叠加的属性。

前几重所需飞升点一览：

| 叩开重数 | 所需飞升点 | 累计投入 |
| ---: | ---: | ---: |
| 第 1 重 | 100 | 100 |
| 第 2 重 | 200 | 300 |
| 第 3 重 | 400 | 700 |
| 第 4 重 | 800 | 1500 |
| 第 5 重 | 1600 | 3100 |
| 第 6 重 | 3200 | 6300 |
| 第 7 重 | 6400 | 12700 |
| 第 8 重 | 12800 | 25500 |
| 第 9 重 | 25600 | 51100 |

重数越高，所需越是浩瀚；第九重之后仍以同一规矩倍增。面板会随时显示当前重数与下一重的进度。

### 重数奖赏

| 重数 | 一次性绑定奖励 | 称谓 |
| ---: | --- | --- |
| 1 | — | 天门初叩 |
| 3 | 保命符 ×1 | 玄关有应 |
| 6 | 转修令 ×1 | 道痕初成 |
| 9 | 天外残玉 ×1 | 太虚留名 |
| 12 | 炼虚丹残方 ×1 | 天门将启 |

- 第 3、6、9、12 重的奖励均为一次性**绑定**物品，叩开即赐。
- 更高重数不再发放实物，用于称谓与榜单展示，是留名仙途的资历。

## 修行建议

- 化神圆满后若不急于破境，继续闭关凝点、每周完成试炼，是飞升点最稳的两条来路。
- 被动先齐头并进还是专攻一项，悉听尊便；但叩问天门需四项皆满 5 级，终究要雨露均沾。
- 天门费用倍增，前期每重尚廉，后期所费甚巨；投入之前想清楚，递出的飞升点收不回来。

## 常见问题

### 为什么我不能挑战飞升试炼？

常见原因：

- 还未达到化神圆满。
- 本周已经完成过飞升试炼。
- 道行不足。

### 化神圆满后继续闭关有什么用？

若暂未突破炼虚，溢出的修为会按规则转为道行与飞升点，用于道途升阶、飞升试炼与飞升被动；突破炼虚后，炼虚圆满才是新的修为顶点，此后继续闭关依旧凝点。圆满之后，闭关从来不是空转。

### 被动没升满，飞升点能先存着叩天门吗？

不能。叩问天门要待四项被动均达 5 级后才开放；此前的飞升点只能用于升级被动——好在升满四项之后，天门自会开门迎客。

### 天门投错了能撤回吗？

不能。投入天门即不可撤回，但不足一重的进度永久保留，不会清零。递出之前，请量力而行。
