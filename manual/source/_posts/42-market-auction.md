玩家经济系统提供两类交易渠道：坊市用于堆叠物品的一口价快速流通，拍卖行用于带词条法宝实例与白名单高阶材料的竞价价格发现。二者分工明确，服务于不同物品类型与交易需求。

## 坊市

坊市是玩家一口价交易入口，当前在私聊中使用。

### 基本操作

在 `/market` 界面可执行以下操作：

- 浏览：查看当前在售挂单。
- 购买：支付灵石购买其他玩家的挂单。
- 上架：将自己的非绑定可交易物品上架，并调整上架数量和总价。
- 撤单：撤回自己的挂单，返还物品到储物袋。

### 上架规则

上架时会从储物袋中扣除物品，撤单会返还。购买会支付灵石，卖家获得扣税后的灵石。

坊市主要交易背包里的材料、丹药等堆叠物品，不交易法宝实例。

### 交易限制

以下物品无法上架：

- 绑定物：所有绑定物品均不可上架。
- 关键物品：化神丹、炼虚丹、转修令、保命符等关键物品即使以非绑定形式进入背包，也不可上架。
- 法宝实例：当前坊市不交易法宝实例。
- 本命法宝：本命法宝或绑定法宝不可上拍；斩缚后仍保留绑定，不会重新流入市场。

### 税费

坊市成交会收取一定比例的税费，卖家获得扣税后的灵石。具体税率以游戏内实际显示为准。

## 拍卖行

拍卖行是法宝实例与白名单高阶材料的竞价交易场所，用于承载坊市不收的带词条法宝实例，让高价值产出有价格发现机制。

### 拍卖机制

拍卖行采用英式拍卖模式，可选一口价。主要规则如下：

| 项 | 规则 |
| --- | --- |
| 拍期 | 24 小时 |
| 起拍价 | 卖家自定，须≥系统底价 |
| 加价幅度 | 每次出价至少比当前价高 5% |
| 一口价 | 可选设置，须≥起拍价×1.2；出价达到立即成交 |
| 防狙击 | 最后 5 分钟内出价，结拍时间顺延 5 分钟，最多顺延 6 次 |
| 挂拍费 | 起拍价的 1%，至少 1 灵石，挂拍时扣除不退 |
| 成交税 | 10%，从卖家实际收入中扣除 |
| 同时挂拍 | 每人最多同时 3 场拍卖在进行中 |
| 撤拍 | 无人出价时可撤拍，挂拍费不退 |

### 系统底价

系统按法宝品阶设定底价，起拍价不得低于系统底价：

| 品阶 | 系统底价 |
| --- | ---: |
| 凡 | 50 灵石 |
| 灵 | 200 灵石 |
| 宝 | 800 灵石 |
| 玄 | 3000 灵石 |

### 可拍物品

拍卖行承接的物品类型如下：

- **可拍**：
  - 法宝实例：带词条、含强化等级的装备实例。
  - 白名单高阶材料：星陨砂、幽都魂晶、天外残玉、雾泽虚砂、裂海空髓、混沌残核。

- **不可拍**：
  - 绑定物（`bound=1`）。
  - 炼虚丹、化神丹、转修令、保命符等坊市禁售名单物品。
  - 普通材料与丹药继续走坊市。

### 托管与锁定

法宝实例上拍时必须实际托管：

- 上拍时校验法宝未装备，并置为拍卖托管状态。
- 托管中的法宝无法装备、强化、重铸、分解、赠送或再次上拍。
- 成交过户或流拍退回时恢复为正常状态，与灵石结算在同一事务内完成。

材料类沿用坊市模型：上架即扣库存，流拍或撤拍退回。

### 资金结算

出价时立即从灵石中实扣，写入托管账户。被超价时原子退回。余额永远反映真实可用灵石，不存在"冻结额"概念。

结拍由定时任务驱动，结算幂等。拍卖状态单向变化（`active → sold/passed/cancelled`），重复触发结算不会重复发放。

成交时同一事务内完成：法宝过户、托管资金转卖家（扣税）、事件播报。流拍时物品退回、托管全额退款。

### 提醒机制

为应对低流动性群体中的曝光问题，拍卖行提供以下提醒：

- 新拍上架时群播报。
- 结拍前 1 小时群播报。
- 玩家可关注某场拍卖，被超价或临近结拍时收到私聊通知。

### 天价成交播报

成交价达到 100 万灵石以上时，系统会在全服播报，作为群内可见的交易审计信号。播报有窗口期限制，避免刷屏。

## 二者分工

坊市与拍卖行服务于不同的交易场景：

| 方面 | 坊市 | 拍卖行 |
| --- | --- | --- |
| 交易模式 | 一口价 | 竞价（可选一口价） |
| 物品类型 | 堆叠物品（材料、丹药） | 法宝实例、白名单高阶材料 |
| 定价方式 | 卖家固定 | 价格发现 |
| 适用场景 | 日常材料流通、快速变现 | 高价值物品议价、词条法宝交易 |

坊市适合日常材料的快速流通，交易成本低、流程简单。拍卖行适合高价值物品的价格发现，尤其是带词条的法宝实例和稀有高阶材料，通过竞价机制形成合理价格。

## 注意事项

### 本命法宝与绑定

本命法宝和所有绑定法宝都不可上拍、不可分解。认主前请先想清楚，莫让一时心热误把镇命之器锁死。

若日后想更换本命，可以斩缚。斩缚会清空原本命等级，并解除角色当前本命指向；但那件法宝仍保持绑定，也不可再次认主，不能重新流入交易或分解套现。

### 审计与反套利

拍卖行复用坊市审计口径：异常价格、高频对倒会触发审计日志。拍卖行只转移灵石不产生灵石，挂拍费与成交税是净 sink，用于防止经济失衡。

### 禁售物品

化神丹、炼虚丹、转修令、保命符等关键物品，即使以非绑定形式进入背包，也不可在坊市或拍卖行上架。这些物品通常通过秘境、世界 Boss、周活动商店等渠道获取，设计意图是让玩家通过玩法获得，而非直接交易。
