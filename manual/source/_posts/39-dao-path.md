元婴之后，境界不再是唯一的成长方向。道途是与境界突破并行的专修长线：同境界的道友，自此有了玩法倾向之别。本章说明道途的择取、升阶、转修与道行的来路。

## 道途定位

- 达到**元婴初期**后，可在 `/path` 中选择第一条道途，**首条免费**。
- 道途不替代境界突破：可以一心破境，也可以边突破边专修。
- 元婴圆满而尚未突破化神时，道途仍提供持续积累的去处；化神之后的内容会让道途收益更加明显。
- 同一时刻只有一条**主道途**生效；已修过的其他道途进度保留，详见下文转修。

## `/path` 面板

在机器人私聊发送 `/path`，可以看到：

- 当前**道行**；
- 「已悟道途」列表：每条道途的等阶、当前加成方向，主道途带「当前」标记；
- 尚未参悟的道途及其定位；
- 对主道途的「升阶」入口、对已悟道途的「转修」入口，以及对未悟道途的「选择」入口。

尚未择道的元婴修士，面板会列出五条道途供免费择一；已有道途的修士再想入门新道途，走的便是转修流程。

## 五类道途

| 道途 | 定位 | 适合怎样的道友 |
| --- | --- | --- |
| 剑修 | 攻伐与 Boss 伤害 | 好攻伐，常参与世界 Boss 合击、冲击伤害榜 |
| 体修 | 生存与秘境推进 | 重续航，希望在秘境中走得更远、连战更稳 |
| 丹修 | 丹药与突破辅助 | 勤于炼丹，看重突破与渡劫的容错 |
| 器修 | 法宝与强化 | 经营法宝长线：炼器、强化、重铸与本命喂养 |
| 符阵 | 闭关与洞府效率 | 节奏从容，以闭关积累为主的清修之士 |

> 择道只看玩法偏好，不必纠结「哪条最强」：首条免费，且日后可转修，各道途进度都会保留。

### 剑修

攻伐一路，长处在输出与爆发。世界 Boss 单次挑战按一段战斗计伤害，剑修在合击中更容易把伤害打足，在伤害榜与限回合的高防目标面前尤为得力。好勇斗狠、以榜上有名为乐的道友，剑修是顺手的兵刃。

### 体修

生存一路，长处在气血与抗压。秘境逐层连战、中途无法补给，气血与法力的存量决定能深入几层；体修的厚实身板让连战更稳、重伤之后也更快回到可战状态。常觉「差一层就能过」的道友，体修能补上这口气。

### 丹修

补给一路，长处在丹药与突破辅助。炼丹的产出与效果更佳，冲击大境界与渡劫时的容错也更宽——天劫、神魂劫、虚空劫当前，多一分丹道护持便多一分底气。以炉鼎为业的道友，此道与 `/craft` 日常最相合。

### 器修

法宝一路，长处在炼器与强化：炼器收益、强化重铸的花费、法宝分解的所得，器修都更占便宜。本命法宝长线尤甚——器修喂养本命更省灵石与器魂，只是等级上限与各道相同。志在打造镇命之器的道友，宜由此入。

### 符阵

清修一路，长处在闭关与洞府效率：同样的真实时辰，符阵修士积累得更多，与宗门福利、飞升被动等共用闭关增益总上限。前台时间不多、以离线积累为主的道友，符阵让每一寸光阴都不虚度。

## 道途等级与升阶

每条道途的等阶依次为：

```text
入门 → 小成 → 大成 → 圆满 → 宗师
```

择取道途即为「入门」；其后各阶在 `/path` 中消耗资源升阶：

| 升阶 | 消耗 |
| --- | --- |
| 入门 | 选择即得（首条道途免费） |
| 小成 | 道行 |
| 大成 | 道行 + 星陨砂 |
| 圆满 | 道行 + 幽都魂晶 |
| 宗师 | 道行 + 天外残玉 + 飞升点 |

- 星陨砂、幽都魂晶、天外残玉是化神期材料，产自化神历练地图与秘境，也可用于高阶炼制；周活动商店亦能兑换部分道途材料。
- 飞升点来自飞升体系，化神圆满后开始积累，详见[飞升](/manual/40-ascension/)。
- 等阶越高，该道途方向上的增益越明显；各项加成均受全局合算上限约束，不会让单一路线越过天道限制。

> `/path` 面板中另有「淬炼」入口，可消耗道行进一步深化当前道途，层数与消耗以面板显示为准。

## 转修

转修是「更换主道途」，不是清空重练：

- 切换主道途需要 **1 枚绑定转修令** 与一笔灵石。
- 转修后有冷却期，冷却未过不能再次转修。
- **已修过的道途进度全部保留**，切回旧道途时等阶仍在，不做折损。
- 当前主道途不能作为转修目标。

转修令的规矩：

- 常见来源为化神秘境太虚天门与周活动商店。
- NPC 商店不直接出售转修令。
- 转修令默认绑定，属于坊市限售的关键物品，不可上架套现。

这套规矩意在鼓励道友试行不同路数，而非惩罚「入错门」。

## 道行的来路

道行是道途升阶与飞升试炼都要用到的资源，**不可交易、不可被夺取**。常见来源：

| 来源 | 说明 |
| --- | --- |
| 周活动副本 `/weekly` | 每周稳定来源，道行有每周上限 |
| 高境界圆满后的溢出转换 | 元婴圆满未破化神、化神圆满未破炼虚、炼虚圆满之后，继续闭关的溢出修为会按比例转为道行 |
| PvP 月赛季 | 天梯月度赛季结算奖励 |
| 宗门战赛季 | 月末宗门战据点赛季结算奖励 |

此外，师徒传承中的突破里程碑、周活跃回报与出师礼，也会给师父一方带来少量道行，详见[师徒与道侣](/manual/38-bonds/)。

## 选择建议

- 常打世界 Boss、看重贡献榜名次者，宜剑修。
- 秘境常在某层折戟、历练连战吃力者，宜体修。
- 常炼丹、正在筹备大境界突破与渡劫者，宜丹修。
- 专注法宝词条、强化重铸与本命喂养长线者，宜器修；器修喂养本命法宝也更省灵石与器魂。
- 日常以闭关为主、前台时间不多者，宜符阵。

道途收益与对应玩法的内容瓶颈相配，选与自己日常循环相合的那条，收益自然最大。拿不准时先择一条起步——首条免费，转修有代价但进度不失，仙途容得试错。

## 常见问题

### 为什么我不能选择道途？

道途自元婴初期起开放。境界未至元婴，`/path` 只会提示你先行破境。

### 为什么我不能转修？

常见原因：

- 境界还未达到元婴。
- 缺少绑定转修令。
- 灵石不足。
- 转修冷却未结束。
- 当前主道途已是目标道途。

### 转修后原来的道途等级还在吗？

在。各道途的等阶与进度各自保留，切回旧道途时原样生效，不做经验折损。转修换的是「当前主修」，不是推倒重来。

### 道行总是不够，哪里来得多？

每周的周活动副本是稳定来路，但有每周上限；圆满后的溢出转换是长线来路，境界到顶后闭关不止、道行不竭；PvP 月赛季与宗门战赛季则是周期性的补充。几路并行，积少成多。
